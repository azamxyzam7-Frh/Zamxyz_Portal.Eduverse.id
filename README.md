# Zamxyz'Portal Eduverse.id

Website pembelajaran statis yang siap digunakan di GitHub Pages.

## Fitur
- Materi lengkap pada 7 mata pelajaran: Fisika, Biologi, Matematika, Sejarah, Geografi, Teknologi, Astronomi.
- 28 topik materi.
- Pencarian dan filter materi.
- Tampilan detail materi.
- Penanda materi selesai dengan localStorage.
- Statistik progress dan skor terbaik.
- Kuis acak berdasarkan mata pelajaran.
- 30 soal kuis.
- Fakta menarik.
- EduAI lokal (tanpa API key/server).
- Jam mengikuti zona waktu perangkat pengunjung.
- Profil belajar lokal.
- Mode terang/gelap.
- Responsive untuk Android dan desktop.
- Tidak membutuhkan framework atau library eksternal.
